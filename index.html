Flexbox Children Reminder

The parent must use display: flex;. Give a child its own class, then place child properties in that child rule.

<div class="cards">
  <section class="featured">Featured Club</section>
  <section>Another Club</section>
</div>

.cards {
  display: flex;
}

.featured {
  order: -1;
  align-self: center;
  flex-grow: 2;
}

Debug 2: Target the correct element

Hint

align-self controls one child. For this task, its value must be center.

Debug 3: Declaration punctuation

Hint

Check the punctuation between the property and value and at the end of the declaration.

Write Child Rules

Apply Flexbox Child Properties
